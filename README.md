# Simple Task Manager

A simple task management web application built using HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks to help organize their daily work.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Add tasks by pressing the Enter key
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Simple-Task-Manager/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/simple-task-manager.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional software or dependencies are required.

## How to Use

* Type a task into the input field.
* Click the **Add** button or press **Enter**.
* Click on a task to mark it as completed.
* Click the **Delete** button to remove a task.
